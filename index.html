The Design Basis

Engineering failures, told from the investigators' own reports

A YouTube documentary channel. Every episode is built from a public investigation report (NTSB, CSB, NERC/FERC, ENTSO-E and others), cited page by page.

Watch the channel: youtube.com/@thedesignbasis

The Design Basis Uploader

The Design Basis Uploader is a private desktop tool used only by the channel operator. It connects to the operator's own YouTube channel through the YouTube Data API to set titles, descriptions, tags, thumbnails, captions and scheduled publish times on videos the operator has already uploaded, and to read the channel's own statistics. It is not offered to other users.
