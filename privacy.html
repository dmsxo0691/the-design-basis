Privacy Policy — The Design Basis Uploader

Effective date: 3 October 2026

The Design Basis Uploader ("the app") is a desktop tool run by the operator of the YouTube channel The Design Basis to manage that channel. The app is used only by its operator on the operator's own computer. It has no other users, no website accounts and no servers of its own.

What the app accesses

When the operator signs in with Google and grants permission, the app uses the YouTube API Services to access the operator's own YouTube channel:

  • Basic channel information (channel name, ID, handle) and the list of the channel's uploaded videos.
  • Video metadata the operator chooses to change: titles, descriptions, tags, category, privacy status and scheduled publish time.
  • Thumbnails and caption tracks the operator uploads for those videos.
  • The channel's own YouTube Analytics reports (read-only), used to review how the channel's videos perform.

The app does not access any other person's data, does not read comments or messages, and does not collect information about viewers.

How the data is used

The data is used only to perform the action the operator starts, such as scheduling a video or attaching captions, and to show the operator their own channel information. It is not used for advertising, profiling or any other purpose.

Storage

The OAuth access and refresh tokens issued by Google are stored in a local file on the operator's computer and are never uploaded anywhere. Channel information returned by the API is kept only in local files on the same computer (for example, the IDs of the operator's own videos). Nothing is stored on any server operated by the app.

Sharing

The app does not sell, rent, transfer or disclose Google user data to anyone, and does not send it to any third party, including AI model providers. Data is exchanged only between the operator's computer and Google's APIs.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube API Services

The app uses YouTube API Services. By using the app you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Revoking access and deleting data

Access can be revoked at any time from the Google Account security settings at myaccount.google.com/permissions, or through the Google security settings page. Deleting the local token file removes all stored credentials; the app keeps no other copy.

Changes

If this policy changes, the updated version will be posted on this page with a new effective date.

Contact
